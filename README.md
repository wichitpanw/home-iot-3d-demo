# บ้านของฉัน — Interactive 3D Home

เว็บสาธิตแบบจำลองพื้นที่บ้าน 3 มิติ สร้างด้วย Three.js รองรับการหมุน ซูม เลื่อนมุมมอง โหมดกลางวัน–กลางคืน และไฟจำลองสามโซน

หมุดกล้องในเวอร์ชันสาธารณะเปิดภาพ Snapshot ที่บันทึกไว้เท่านั้น ไม่มีการเชื่อมต่อกล้องจริง ไม่มี UID, IP, บัญชีผู้ใช้, PIN หรือระบบ PTZ

## เปิดในเครื่อง

```bash
python3 -m http.server 8080
```

จากนั้นเปิด `http://127.0.0.1:8080/`
